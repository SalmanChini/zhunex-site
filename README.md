# Zhunex — GitHub Pages

این پوشه نسخهٔ ایستای سایت است. سرور لازم ندارد.

1. در گیت‌هاب یک مخزن جدید بسازید.
2. همهٔ فایل‌های همین پوشه را در ریشهٔ مخزن بگذارید، نه داخل یک پوشهٔ اضافه.
3. Settings → Pages → Branch: main و پوشهٔ / (root).
4. Custom domain را بگذارید: zhunex.site
5. در DNS دامنه این چهار رکورد A را برای ریشه بگذارید:
   - 185.199.108.153
   - 185.199.109.153
   - 185.199.110.153
   - 185.199.111.153
6. اگر www می‌خواهید، یک CNAME از www به username.github.io

زبان‌ها دو نسخهٔ جدا هستند: انگلیسی در ریشه، چینی زیر /zh/
